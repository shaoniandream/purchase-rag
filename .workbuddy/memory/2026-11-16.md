## purchase-rag 项目 README 编写

- 项目定位：手写 RAG 学习实践项目（不依赖 LangChain）。技术栈：Express 5 + TypeScript(ESM, tsx) + Zod + PostgreSQL/pgvector + Ollama bge-m3(1024维) + DeepSeek(OpenAI 兼容)。
- 现有能力：14 条模拟采购知识(policy/process/product/specification/faq) → ingest 批量事务 Upsert → retriever 余弦距离 Top-K(4) → ragService 拼 knowledge_context 调 LLM → 返回 answer + sources。
- 代码事实：表 purchase_knowledge(id,title,content,category,embedding vector(1024),updated_at)；接口 POST /api/rag/chat（Zod 限 1–2000 字符）；脚本 npm run dev / npm run ingest；调试脚本 src/test/test-embedding.ts、test-retrieval.ts。
- 本次产出：README.md（含 mermaid 架构图、DDL、接口示例、设计取舍、已知局限清单）、.gitignore、.env.example。
